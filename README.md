# Movie-recommendation-system
Content based movie recommendations using NLP  and cosine similarity

## Dataset

This project uses TMDB movie metadata for generating content-based movie recommendations.

The dataset files are not included in this repository because of their size.

**To get the dataset:**
1. Download the TMDB 5000 Movie Dataset from [Kaggle](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata).
2. Extract the downloaded files.
3. Place the required CSV files in the project directory, following the filenames and paths used in the notebook.

Please check the notebook for the exact dataset filenames required.
